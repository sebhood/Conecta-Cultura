# Conecta Cultura
Proyecto incremental de la asignatura Desarrollo FullStack II.
## Primera etapa
- Estructura HTML inicial.
- Hoja de estilos externa.
- Archivo JavaScript enlazado.
## Ejecución
Abrir `index.html` en el navegador o utilizar Live Server.

## Segunda etapa
- Sitio multipágina: Inicio, Nosotros, Noticias y dos detalles de noticia.
- Estructura semántica (header, nav, main, section, article, aside, footer).
- Navegación con rutas relativas y `aria-current` en la página activa.
